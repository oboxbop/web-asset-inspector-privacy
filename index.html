Privacy Policy

Web Asset Inspector Chrome Extension
Last updated: September 14, 2026

1. Overview

Web Asset Inspector is a Chrome extension that helps users inspect image and font resources loaded by webpages they visit, preview those resources, and save selected assets to their device.

This Privacy Policy explains what information the extension can access, how that information is used, and how it is protected.

2. Information the extension can access

To provide its core functionality, Web Asset Inspector may access:

  • The URL and basic information of the active browser tab.
  • Network request metadata for image and font resources loaded by the active webpage.
  • Image resources, font resources, MIME types, filenames, dimensions, and related metadata required for preview and download.
  • Locally stored extension preferences, such as view mode, preview size, filters, selected items, and interface settings.
Images Fonts Resource URLs Local preferences

3. How information is used

The information above is used only to provide the extension's disclosed features, including:

  • Detecting image and font resources loaded by the webpage.
  • Displaying those resources in the extension side panel.
  • Previewing image assets and fonts.
  • Converting supported web-font formats locally when requested.
  • Downloading files only after a user-initiated action.
  • Remembering local interface preferences.

4. Local processing

Web Asset Inspector is designed to process inspected webpage resources locally in the user's browser. The extension does not send captured browsing history, inspected image assets, font files, or resource lists to developer-operated servers.

5. Data sharing and sale

Web Asset Inspector does not sell user data. It does not share browsing activity, inspected assets, or captured resource data with advertisers, data brokers, or other third parties for advertising, profiling, or unrelated purposes.

When a user opens an original resource or downloads a file, the browser may communicate directly with the website or content-delivery network hosting that resource as part of the normal web request.

6. Data storage and retention

The extension may store local preferences using Chrome's extension storage APIs. These preferences remain on the user's device/browser profile and are used to improve continuity of the extension interface.

Users can remove locally stored extension data by uninstalling Web Asset Inspector or clearing extension/site data through Chrome.

7. Chrome permissions

  • webRequest — to detect image and font resource requests loaded by webpages.
  • tabs — to associate the extension panel with the active tab and support user-requested navigation actions.
  • sidePanel — to display the extension interface beside the webpage.
  • downloads — to save files when the user explicitly requests a download.
  • storage — to save local extension preferences.
  • Website access permissions — to inspect image and font resources from webpages where the extension is used.

8. Security

The extension is designed to minimize data collection and to use accessed information only for its stated functionality. It does not execute remotely hosted extension code.

9. Children's privacy

Web Asset Inspector is a utility tool and is not directed toward children. The extension does not knowingly collect personal information from children.

10. Changes to this policy

This Privacy Policy may be updated when extension functionality or legal requirements change. The "Last updated" date at the top of this page will be revised when material changes are made.
